# 博客列表 V2：全局标签及真实热门

该 PR 将原本对单页 12 篇文章做“热门”和标签统计的逻辑改为服务端全库查询。热门按已发布文章的 `view_count DESC` 排序，空/零浏览不充热门；一周或全站榜单需要后续更精确的去重浏览分析。统计时按 COUNT(DISTINCT posts.id) 去重，标签计数不包括草稿。

标签筛选变为可分享的 `/blog?tag=...`，第 2 页能跨整库继续查找，不再受前 12 篇限制；分类后的翻页保留 tag。页面仍保留“当前页文本快速过滤”，不冒称跨库关键词全文检索（全站搜索仍使用 `/search`）。首屏最新 3 篇独立，剩余本页文章全部展示，不会因为新增全站热门文章而丢失第 4–8 篇。

不需要 Neon migration，不改现有文章、计数、收藏或用户数据。上线前验收：RAG 分类文章数跨分页稳定、热门不再固定显示最新第 4–8 篇、游客看不到草稿标签；空流量网站不显示虚构热门。
