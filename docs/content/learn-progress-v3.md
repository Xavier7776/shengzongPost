# 本机学习进度（M07-A）

打开文章只写既有 `arc_reading_history` 浏览记录，不开始或完成学习。点击开始、自测选项或实践确认才建立本机学习记录。状态为未开始、学习中、已确认实践、已完成；完成需全部当前版本自测正确、主动确认实践、再点击完成。答错或取消实践会撤销完成时间，取消完成保留答案和实践确认。实践由读者自报，本站不运行练习或验证能力。

`mindstack:learn-progress` 为 version=1 的本机 localStorage；保存 Slug、标题、完整 Edition 指纹、状态、答案索引、实践确认、文章相对像素位置、上次章节、更新时间与完成时间。最多保留最近更新 100 期，解析总输入上限 200,000 字符；未知 Schema、损坏 JSON、不合法字段安全忽略。内容更正后旧记录保留到下一次主动学习动作，届时以新指纹重新记录，旧答案不能完成新版本。重置须确认且只删除本期新记录，保留其他期和旧浏览历史。

刷新和同源多标签页同步通过 storage 事件及同页自定义事件；每次动作先读取最新记录，再更新本期，冲突采用最后动作覆盖本期。不是跨设备或账号同步。共享浏览器的其他人也能看见记录，未加密；不上传学习行为，不因登录/退出切换用户归属。原有匿名浏览计数保持既有行为，无法访问 sessionStorage 时跳过去重计数，避免异常或失控重复上报。

存储禁止、读取异常或写入配额失败时，本页保留内存答案与完成状态并显示保存失败提醒；离开后可能丢失。旧浏览历史和字号/模式也捕获存储异常，默认字号和本页调整可用。已加载文章的学习动作不依赖数据库或 HTTP。

位置每秒最多保存一次，离页 pagehide 补保存；普通打开不自动跳转。读者点击恢复按钮或 `/learn` 的继续学习链接 `?resume=1` 才即时恢复，链接禁用 Next 默认滚动复位。像素位置随窗口宽度、字号或图片布局变化可能偏移，章节名帮助定位；此版不宣称跨设备精确锚点。SSR 与原目录标题不变，Edition 指纹/正文保持原契约。

`/learn` 分开显示浏览与本机完成记录、最近未完成继续入口、当前归档页学习中/待练习/已完成筛选。计数来自最多 100 期的本机记录，可能包含已撤回或更正的旧版本；不当作当前公开有效完成数量。详情打开后以当前指纹复核。筛选明确只覆盖当前页，服务器主题/分页总量不改。
