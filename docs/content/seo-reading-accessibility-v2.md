# M09 SEO 与阅读体验

基线为 M08 合并提交 `8f74cdc3588d1d180b81d43b882340616f322474`。本轮补齐 Blog、Learn、Work 的绝对 canonical、OG/Twitter 和面包屑；Article 使用数据库实际发布日期/更新日期，CreativeWork 使用实际记录时间并以项目页为实体 URL。全站使用现有 `getSiteUrl`，JSON-LD 转义 `<` 防止文本结束 script 标签。搜索与 Learn 查询变体 noindex，sitemap 去除搜索入口，私有页面通过响应头及 robots 排除索引。

文章标题生成内容相关且去重的稳定 ID，保留旧的 `blog-toc-heading-N` 和 `learn-section-N` 链接。普通 HTML 在消毒之后标注 ID，结构化精读的所有锚点直接由 React 渲染；答题时 ID 保持不变。第一次浏览器复核曾发现目录脚本插入子节点导致 React 418/422 水合错误，已去掉这类 DOM 插入，完整浏览器复核零错误。标题文字改变或重复标题数量改变时仍需要编辑者评估旧深链；不承诺任意改文后的标题 ID 都不变。
