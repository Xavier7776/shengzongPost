# 技术精读发布状态看板 V1

新增只读页面 /admin/learn，使用 requireAdmin 的当前数据库角色复核。展示最近 60 期结构化专刊的发布状态、Schema 合规性、文章正文与 Edition JSON 的一致性，以及北京时间当日是否有刊物记录；无编辑、删除和自动重试功能。

## 运营规则

* 显示“正常”仅意味着 validateEdition 结构检查通过且 textVersion(Edition) 与 posts.content 完全一致，并不意味着论文事实核验完成。
* 若显示“正文与结构数据不一致”，说明网站的结构化阅读器有可能回退纯文本，应单独追踪管理员手动编辑历史。
* “今日缺失”不必然等于故障，须结合 ChatGPT 08:30 任务的运行结果判断。
* 后续版本可增加发布事件审计表、任务失败通知、选题去重和原文链接健康检查；其迁移必须在 Neon 临时分支验证并获得单独的生产授权。

## 验收
需测试普通用户无法访问，SQL 不在 requireAdmin 前调用；旧文章无任何变更；没有 Neon 写入；最近 60 期出现数据漂移时有明显警告。
