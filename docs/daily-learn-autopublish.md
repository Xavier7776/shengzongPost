## 离线预检

```powershell
npm run learn:validate -- C:/path/to/candidate.json
```

命令读取一个候选 JSON 文件，复用 `lib/learn/document.ts` 的 `validateEdition`、`chinaDate`，及 `publication-contract.ts` 的 canonical JSON、SHA-256 指纹与 `textVersion`。只接受北京时间当日的 v1/v2 合规文档；无历史日期覆盖或发布参数。

- 成功：退出码 0，单行 JSON 包含 `scope=offline_validation_only`、日期、版本、slug、指纹、正文长度和 UTF-8 字节数。
- 失败：退出码 1，单行 JSON 列出校验错误；文件或 JSON 错误不回显文稿/环境值。
- 不加载环境文件、不取密钥、不联网、不生成文稿、不连接数据库、不发布。无需每天人工复制；此命令是可复用校验入口，尚不是任务集成或写入通道。
- 校验只覆盖结构、来源字段、引用与安全约束，不独立验证论文事实，也不证明来源公网可达。

## 保留的服务端协议

`lib/learn/publish.ts` 已实现校验、来源检查、完整指纹、原子写入、独立回读和有界公网核验；`lib/learn/operations.ts` 已有只读运维判定。不新增重复校验器、发布器或监控表。完整语义见 [发布契约](operations/learn-publication-contract.md)。

`POST /api/internal/learn/publish` 保留 HMAC-SHA256、2 分钟时间窗、180KB、当日日期及冲突拒绝规则；现有受控接口不代表 ChatGPT 已有授权 HTTP 调用能力。不得取密钥绕过平台阻断，不得直写 SQL 绕开门槛。

| 阶段 | 必须保留的证据 |
|---|---|
| 调度 | 当前计划与实际运行 ID、时间、状态；文稿消息时间不足以证明调度 |
| 生成 | 完整候选 JSON；成功消息不是质量结论 |
| 质量 | 同版校验结果、完整指纹、来源与事实审查结论 |
| 写入 | 经验证授权通道的明确结果；拒绝/未知不得宣称已写 |
| 回读 | posts/edition 一对一、完整文档与派生正文一致；写入返回不代替回读 |
| 公网 | Blog/Learn/详情可达且内容指纹一致；延迟时不重复插入 |

`written_unverified` 或 `public_pending` 先只读排查，不删除或覆盖恢复。不得以旧刊存在反推某次任务成功。
